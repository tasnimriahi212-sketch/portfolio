## The caption formula

```
HOOK (line 1 — the only thing visible before "...more")
↓
VALUE (2–4 short lines — the meat)
↓
CREDIBILITY (1 line — who you are / a result)
↓
CTA + QUESTION (one action + one question to spark comments)
```

## Hashtags — 3 sets, rotate them

Use **5–8 per post**, mixing one "reach" set with one "niche" set. Don't repeat the same block every post.

**Dev/reach:** `#softwaredeveloper #webdevelopment #pythondeveloper #buildinpublic #startuptips #smallbusinessowner`
**Cyber/niche:** `#cybersecurity #pentesting #infosec #ethicalhacking #dataprotection #cybersecuritytips`
**Buyers/local:** `#customsoftware #hiredevelopers #digitalagency #freelancedeveloper #techconsulting` (+ your `#yourcity` tags — local clients convert best)

Rules of thumb:
- 1–2 BIG tags (1M+ posts) + 3–4 medium (50k–500k) + 2–3 small/local
- Never use banned/spammy tags (#follow4follow etc.) — kills reach
- Put them in the caption end or first comment — both fine, just be consistent

## Story sticker playbook

- **Poll before a post:** "Does your business have a security audit? Yes / ...what's that?" → post the audit service next day
- **Quiz:** phishing-spotting, password myths → wrong answers become your next reel
- **Question box:** "Ask a dev or a hacker anything" → each answer = a story + a post idea
- **Countdown:** before launching a client project → "going live in 3 days"
